# 🌍 Travel Log Web App

> A full-stack MERN application to capture, manage, and explore travel experiences efficiently.

---

## 📖 Overview

Travel Log is a modern web application that allows users to document their travel journeys in a structured and user-friendly way. It enables users to create, update, and manage travel entries, making it a simple digital travel diary.

---

## ✨ Features

* 📍 Add travel locations with details
* 📝 Edit and delete travel entries
* 📂 View all logs in an organized format
* ⚡ Responsive and clean user interface
* 🔁 Full CRUD operations using REST APIs

---

## 🧰 Tech Stack

| Layer    | Technology Used     |
| -------- | ------------------- |
| Frontend | React.js            |
| Backend  | Node.js, Express.js |
| Database | MongoDB             |
| API      | REST APIs           |
| Others   | Axios, Vercel       |

## ⚙️ Getting Started

### 🔹 Clone the Repository

```bash
git clone https://github.com/ad-Dinesh/travel-log.git
cd travel-log
```

### 🔹 Run the Application

#### Frontend

```bash
cd frontend
npm install
npm start
```

#### Backend

```bash
cd backend
npm install
npm start
```
